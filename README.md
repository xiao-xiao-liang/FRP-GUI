# FRP-GUI Pro - 跨平台内网穿透图形化管理工具

一款现代、轻量、开箱即用的跨平台 FRP (Fast Reverse Proxy) 图形化管理客户端与控制台，支持 **Windows、macOS、Linux 和 Android**。

彻底告别繁琐易错的手动 `frpc.toml` / `frps.toml` 配置文件编写，支持场景化向导式极简创建、可视化高级表单与 TOML 源码双向无损实时同步。

---

## 🧭 核心导航体系与功能架构

- **我的连接 (`/profiles`)**：
  - **飞书风格单一表格工作台**：面向桌面用户的高密度数据表格展示，彻底移除卡片切换与状态 Tab，默认每页展示 6 条，且可在分页控件中调整。
  - **高密度飞书数据表格**：
    - **多选列**：复选框支持单项勾选与全选/全不选，批量操作时自动禁用；
    - **连接名称**：紧凑展示连接标题与置顶徽章，下方紧随连接描述（列宽不足时单行截断 `...`，鼠标悬浮时通过 `FeishuTooltip` 展示完整描述），点击名称直接进入配置编辑；
    - **穿透规则**：紧凑内嵌式彩色胶囊与端口映射（TCP 蓝、UDP 青、HTTP 绿、HTTPS 紫、未知灰，无圆点；端口映射显示等宽 `本地端口 → 远程端口`；超过 3 条规则展示前 2 条并附“查看更多（+N 条）”交互，点击唤起规则明细弹窗）；
    - **上次启动**：直接读取运行期 `stats.startTime` 格式化呈现真实启动时间（`YYYY-MM-DD HH:mm:ss`），未记录时呈现 `—`；
    - **操作列**：右侧吸顶固定（`sticky right-0`），横向滚动时操作列始终可见。全面采用项目已有纯 SVG 图标按钮（`RunIcon`、`StopIcon`、`DeleteIcon`、`RefreshIcon`），无文字干扰，全量配备 `aria-label` 与 `FeishuTooltip`；启动中与停止中展示禁用的旋转刷新图标，错误状态保留“修复核心”或“查看启动日志”入口。
  - **穿透规则明细对话框**：支持查看方案内所有穿透规则（包含名称、协议类型彩色高亮、本地 IP、本地端口、远程端口，缺省字段统一展示 `—`），直接展示表头与规则内容，不显示筛选、分组、排序工具栏；严格脱敏，不输出任何 `authToken` 或敏感凭据。
  - **场景化“新建连接”向导**：
    - **六大场景分类**：Windows 远程桌面、SSH 远程终端、公开网站 (HTTP/HTTPS)、家庭 NAS、游戏联机及自定义连接。
    - **场景变体智能联动**：NAS 场景内置群晖 DSM (5000)、Alist 网盘 (5244)、Jellyfin (8096)；游戏场景内置 Minecraft Java 版 (TCP 25565)、基岩版 (UDP 19132)、泰拉瑞亚等，点击变体自动联动端口与默认连接名称。
    - **规范化 Web 穿透**：公开网站场景纯净展示本地端口与自定义域名，不要求且不展示多余的远程公网端口。
    - **“检查并保存”与离线容灾**：提交时统一校验参数并自动探测服务器 TCP 连通性；探测成功直接保存并返回工作台；探测失败醒目展示失败原因与耗时，并提供【重试检测】与人工确认的【仍然保存】（离线保存）。
    - **全链路 Token 安全与脱敏预览**：密码掩码与显隐切换；高级设置区提供实时脱敏（`token = "******"`）的只读 TOML 预览；严禁在日志、Toast 或界面中明文泄露。
    - **无缝转为高级编辑模式**：一键将向导草稿（名称、服务器、Token、协议、TLS 及代理规则）完整带入高级编辑器接管。
    - **核心解耦友好**：未配置本地 FRP 核心时在向导顶部显示非阻断黄色提示，允许先保存配置；仅在实际点击“启动连接”时进行拦截与引导。
  - **更多操作气泡菜单**：编辑配置、查看日志、网络连通性检测、扫码分享、克隆副本、置顶/取消置顶与删除连接收敛至行末更多菜单。
  - **分组、标签与置顶元数据**：底层服务与编辑器保留分组、标签与置顶持久化支持；“我的连接”列表界面聚焦核心数据展示，移除了页面级筛选、分组选择器、标签过滤、搜索框、排序下拉与分组管理按钮，使工作台极为紧凑纯粹。列表始终采用设置项中的默认排序方式稳定渲染。
  - **表格内置批量控制工具区**：
    - **表格边框内嵌入**：批量操作位于表格边框内的右上角，不额外占用表格上方的页面高度；
    - **浮现条件**：未勾选任何项时该区域为空且彻底不占位；勾选一项或多项后浮现批量删除、批量启动、批量停止三个紧凑按钮；
    - **全 stopped 批量启动**：仅当所有选中连接均处于 `stopped` 状态时方可批量启动；若包含非 stopped 项则按钮禁用并提示原因；
    - **全 running 批量停止**：仅当所有选中连接均处于 `running` 状态时方可批量停止，经二次确认弹窗后串行安全停止；
    - **全 stopped 批量删除**：仅当所有选中连接均处于 `stopped` 状态时方可批量删除，二次确认后从列表移除并联动系统安全凭据库清理凭据；
    - **操作防重入**：批量操作执行中锁定所有操作按钮与选择复选框，防止重复点击并发发起请求。
  - **凭据与存储安全边界**：所有分组信息与组织元数据严格仅包含公开标识与时间戳；严禁将任何 TOML 源码、Token、服务器密码或私钥持久化至 `localStorage`，持续保障系统安全凭据库的绝对安全边界。
- **桌面壳层架构**：
  - **纯粹无顶栏桌面布局**：移除右侧主体区域的全局冗余顶栏（标题与副标题），主工作区获得最大垂直显示高度；
  - **左侧飞书标准侧边栏**：保留品牌 Logo、标题及所有一级导航项（我的连接、实时日志、FRP 核心管理、服务器节点、设置），将大盘 Logo 赋予“我的连接”，侧边栏移除冗余的独立“运行状态”项，访问 `/dashboard` 自动重定向至“我的连接”。
- **实时大盘指标卡片（已整合至“我的连接”页面顶部）**：
  - **实时在线看板**：紧凑展示运行实例（运行中 / 总方案）、在线穿透隧道（在线 / 总隧道）、需要处理（异常 / 警告方案）以及当前激活的 FRP 核心引擎版本与就绪状态；
  - **定向排障引导**：存在连接异常或错误时在看板下方展示引导横幅，点击直接定向打开首个异常方案的网络诊断上下文。
- **实时日志 (`/logs`)**：
  - 多连接独立与聚合实时日志流查看，支持按日志级别过滤、高亮、关键字匹配与日志导出。
- **FRP 核心管理 (`/cores`)**：
  - **卡片 / 表格双视图无缝切换**：支持飞书风格网格卡片视图（`CoreCard`）与高密度数据表格视图自由切换，切换偏好自动持久化；
  - **100% 自适应列宽与高密度排版**：彻底移除固定像素挤压与冗余滚动条，各列依内容与视口弹性拉伸；
  - **高辨识度紫色胶囊版本标识**：版本号统一采用规范的紫色胶囊加粗呈现（`FeishuPill variant="purple" font-bold`）；
  - **GitHub Release 官方下载量统计**：自动统计各版本全平台资产下载总数并直观展示（如 `52.3k`）；
  - **统一版本库与当前平台匹配**：GitHub Release 是唯一版本列表来源，镜像仅负责传输加速；同一版本只展示一行，只有与当前电脑操作系统和架构一致、且通过 `frpc --version` 验证的本地核心才显示为“已下载”。
  - **双模导入与现代化原生弹窗**：Windows 平台采用原生资源管理器对话框（`IFileOpenDialog`），毫秒级响应无卡顿；支持直接选择官方 `.zip` / `.tar.gz` 压缩包（自动安全解压、校验架构版本并入库），也支持选择已有解压文件夹（递归识别多个 `frpc/frpc.exe`，跳过 `frps` 和无效文件）。
  - **任务式下载与自定义安装路径**：完整保留自定义下载与解压路径能力；下载通过同一条进度依次展示下载、SHA-256 校验、解压和验真，下载阶段显示实时速度与稳定后的剩余时间。取消后仅在 Range/ETag 条件满足时继续下载，目标目录非空、校验失败或压缩包路径越界都会被拒绝。
  - **全生命周期管理**：本地核心自动探测与合规校验、官方发行版一键下载、复制官方下载直链、设为默认核心、路径修改与安全删除。
- **服务器节点 (`/servers`)**：
  - 面向远程 Ubuntu/Debian FRPS 的节点管理工作台，支持 SSH 密码或多行私钥认证配置、默认节点标记与部署预设。
  - **系统安全凭据库与隔离**：用户勾选“记住凭据”后，SSH 密码、私钥和私钥口令写入桌面端操作系统安全凭据库（Keyring）；每个服务器节点均生成稳定的公开凭据引用（如 `frp-gui/server-node/<id>`），而 `frp_gui_server_nodes` 与 `localStorage` 严格仅持久化非敏感元数据，绝不存储任何 SSH 密码、私钥、FRP Token、Dashboard 密码或 sudo 密码。未记住的 SSH 凭据与单次 sudo 密码仅短暂存活于桌面端单次 IPC 请求内存中，派发后或弹窗关闭后立即主动清空。删除节点时，即使未记住 SSH 凭据，也可一键彻底从操作系统凭据库中清理部署生成的 FRP Token 与 Dashboard 密码。
  - **SSH 安全预检与主机信任（P1-C2）**：在桌面端对目标节点执行只读 SSH 预检。首次连接展示服务器的 SHA-256 SSH 主机指纹，由用户显式核验确认后持久化可信指纹；后续每一次连接均严格比对已知可信指纹，指纹变化或不匹配立即阻断。只读识别发行版（Ubuntu/Debian）、CPU 架构（amd64/arm64）、提权模式与 systemd 状态，预检过程不执行任何远程写入。
  - **受控 FRPS 安全部署与服务生命周期管理（P1-C3）**：
    - **桌面版运行边界与系统支持**：仅桌面版原生环境（Tauri）具备远程部署与执行能力；浏览器模拟模式自动阻断部署入口并给出桌面版提示。支持已通过预检的 Ubuntu / Debian（amd64 / arm64）系统，支持 `root`、免密 sudo（`sudo_passwordless`）及需密码 sudo（`sudo_password_required`）三类提权权限（sudo 密码仅通过固定 SSH stdin 通道传递，绝不进入命令参数）。
    - **官方供应链与资产哈希校验**：安装包严格由 Rust 后端按版本和已预检架构构造 GitHub Release 官方地址下载（不接受用户自定义 URL），下载采用流式限额保护，并在远程解压写入前严格校验同 release 的 `frp_sha256_checksums.txt` 文件哈希，校验不符拒绝安装。
    - **固定安装根目录与服务单元隔离**：远程安装目录固定为 `/opt/frp`，systemd 服务名固定为 `frp-gui-frps.service`；采用版本目录软链接与候选配置验证后原子替换机制，严禁修改或污染用户既有的 `frps.service`。
    - **三阶段向导与显式部署确认**：部署向导严格按“配置参数 → 确认变更 → 进度与结果”三阶段执行，确认阶段清晰呈现将要执行的固定步骤、端口、安装路径与服务名称，必须用户显式点击“确认部署”后方可调用远程执行。
    - **服务控制与安全脱敏日志**：对已部署节点提供启动、停止、重启、刷新状态与查看服务日志功能；日志在前后端双重脱敏（按行掩码 `token` 与密码），合并输出截断限制（最大 32 KiB），杜绝敏感凭据泄露。
  - **阶段规划边界**：在“我的连接”创建场景向导中一键复用已部署的服务器节点属于后续 P1-C4 规划，P1-C3 专注于服务端自动化受控部署与节点管理本身。
- **应用设置 (`/settings`)**：
  - 支持选择关闭主窗口时隐藏到系统托盘或退出应用、启动时显示主窗口或直接进入托盘，以及关闭主窗口且有运行连接时退出前确认。
  - 支持设置“Profile 默认排序”（置顶优先、最近更新、名称升序），采用无损字段级回退策略兼容旧配置。
  - 托盘菜单可打开主窗口、停止全部连接或退出应用；隐藏到托盘不会中断已运行的 FRPC 连接。
- **网络诊断与连通性测试 (Diagnostics)**：
  - 靶向探测指定连接或服务器的 TCP 握手延时 (ms) 与端口可用性，探测结果严格按方案隔离更新。
- **双向同步配置引擎 (Dual-Sync Engine)**：
  - 可视化高级表单与 FRP v0.52.0+ TOML 源码编辑器实时无损双向同步。

## 🛠️ 技术架构

- **前端架构**：React 19 + TypeScript + Vite + Tailwind CSS + Radix UI + Lucide Icons + smol-toml
- **后端架构**：Tauri v2 (Rust 异步进程管控与网络探测)
- **多端适配**：
  - **Desktop (Win / macOS / Linux)**：原生子进程托管 + 系统托盘 + 实时日志管道
  - **Mobile (Android)**：Foreground Service 前台常驻通知 + 扫码导入
  - **Web / 浏览器模式**：仅用于界面预览与非运行期表单/TOML 配置调试；普通浏览器环境完全阻断启动、停止、日志与凭据库操作。

## 🚀 快速启动与构建

### 浏览器界面预览

`pnpm dev` 仅用于查看和调试界面。普通浏览器不能启动本机 FRPC、读取实时运行日志、访问系统安全凭据库或执行远程管理操作；它不会生成模拟成功结果。

### 桌面端功能测试

使用 `pnpm tauri dev` 打开 FRP-GUI 桌面窗口。该窗口仍会加载 Vite 开发页面，但具有受控的 Tauri IPC 能力。只有在该窗口中，连接的启动、停止和实时日志才会对应真实的本机 FRPC 进程。

桌面端关闭主窗口的行为由“设置”页控制。选择“隐藏到托盘”后，连接会继续运行；托盘菜单中的“退出应用”会直接停止应用托管的 FRPC 连接后退出，关闭策略中的“退出应用”则可按设置要求确认。

### 导入本地 FRPC 核心

在“FRP 核心管理”点击“选择本地已有 FRP 文件夹”，桌面端会扫描该目录及有限层级的子目录，批量识别其中通过运行期版本校验的 `frpc/frpc.exe`。`frps`、不可执行文件、符号链接和超过扫描安全限制的候选都会明确列为跳过项；只登记与当前电脑平台/架构相符的可用客户端核心。

应用会在导入与编辑保存前执行只读版本检查（支持纯版本号输出及带横幅输出，拦截服务端程序及非执行文件）；只有版本校验通过的客户端核心才会标记为可用并持久化。

如果方案启动失败：
- **“修复 FRPC 核心”**：表示本机核心路径、文件类型或版本校验问题，点击直达核心管理页面重新选择并验证本地 `frpc.exe`，绝不引导无意义的网络排查；
- **“查看启动日志”**：表示 FRPC 已尝试启动但需要排查真实输出（如早退、配置格式不合法），点击直达实时日志面板查看真实 stderr 输出；
- **“网络连通性检测”**：仅收敛在卡片与表格的“更多操作”菜单中，只用于验证服务端端口 TCP 可达性，不能验证本机 `frpc.exe`、Token 或 TOML 配置。

### Windows 安装包分发

为适应不同用户的安装场景，项目提供三种独立命名的 Windows 安装产物：

- **主安装向导（推荐默认）**：`pnpm tauri:bundle:setup`。产出 `FRP-GUI-Pro-x64-setup.exe`。基于中文 NSIS Modern UI 向导，支持自定义安装目录与当前用户免管理员安装；已具备系统 Evergreen Runtime 的 Windows 10/11 设备安装时直接跳过运行时安装，若缺失则静默引导下载 Bootstrapper。
- **在线 MSI**：`pnpm tauri:bundle:msi:online`。产出 `FRP-GUI-Pro-x64-online.msi`。适合企业批量部署或既有 MSI 工作流；安装时在线下载 WebView2 Bootstrapper。
- **离线 MSI**：`pnpm tauri:bundle:msi:offline`。产出 `FRP-GUI-Pro-x64-offline.msi`。嵌入完整离线运行时，适合隔离或无公网环境；包体和首次初始化耗时随 WebView2 版本及设备性能变化，不保证快速完成。

三种产物相互独立、明确命名，不会相互覆盖。构建前请完成 `pnpm install`，并安装项目要求的 Rust、Windows WebView2 和 Windows C++ 构建工具。

> **测试与验证安全边界**：所有离线自动化测试与桌面构建均未连接任何远程 FRPS 服务器，未写入或索取任何真实 Token、SSH 密钥或云主机凭据。
