# 我的连接工具栏与桌面壳层收口设计

## 目标

将“我的连接”页面收口为紧凑的桌面连接清单：批量操作进入表格右上角工具区，移除该页所有筛选、分组、标签、搜索、排序与分组管理入口；协议类型恢复彩色高亮；移除桌面壳层的全局顶栏。

## 范围与边界

不修改 `src/components/ui/feishu-table/FeishuDataTable.tsx`、`FeishuToolbar.tsx` 或任何通用飞书表格组件。现有通用工具栏把“筛选、分组、排序”写死，无法只通过 Props 隐藏；为确保改动只影响“我的连接”，该页改用新的特性内表格组件 `ProfileConnectionsTable`。

新组件复用项目已有的 `FeishuHeaderCell`、`FeishuTooltip`、`FeishuPagination`、`FeishuEmptyState`、`Button` 和 SVG 图标。连接表在自身会话内维护列宽，直接使用 `FeishuHeaderCell` 的白色表头、分隔线与拖拽手柄；不修改通用表格组件，也不引入第三方依赖。

Profile 的分组、标签、置顶、默认排序设置、持久化与编辑入口继续存在；本次只移除“我的连接”列表上的查询和组织控件，不删除数据或服务层逻辑。

## 页面结构

`ProfileList` 不再渲染外层筛选工具栏、类型/分组/标签选择器、关键词输入、排序选择器和“管理分组”按钮。表格边框内始终保留固定高度的右对齐操作区，令表头和数据行的位置不因选择状态变化而跳动；没有选中项时该操作区为纯白空白，不显示文字、图标或占位符。

选中一项或多项时，固定操作区的同一位置右对齐显示：批量删除、批量启动、批量停止。无论是否选中，该区域都保持白底。三个按钮保留现有严格资格与 Tooltip：全部 `stopped` 才能启动或删除，全部 `running` 才能停止；其他状态均禁用。该操作区在表格边框内，不额外占用表格上方的页面高度。

`ProfileConnectionsTable` 仅保留名称、描述、规则、上次启动和固定右操作列；运行状态列由右侧的启动、停止、启动中、停止中和异常操作承载，避免重复信息。表格滚动容器具备明确的最小内容宽度；“操作”表头与单元格使用 `position: sticky; right: 0`，横向滚动时只移动其余列。根表字号降为 13px，正文进一步压缩至 12px 或 11px。

单项启动操作移除蓝色填充背景，改为与批量启动一致的白底/无填充图标按钮：使用现有绿色 `RunIcon`，保留边框、`aria-label` 与 `FeishuTooltip`。停止、删除和更多操作维持既有视觉语义。

## 规则协议高亮

每条规则预览拆分为协议胶囊和端口映射。协议使用无圆点的现有 `FeishuPill`：TCP 为蓝色、UDP 为青色、HTTP 为绿色、HTTPS 为紫色，未识别协议为灰色。端口映射保持等宽灰色文本：`本地端口 → 远程端口`。规则详情弹层的“协议类型”列也使用相同映射，保证列表与明细一致。

## 桌面壳层

从 `App.tsx` 的右侧 `main` 区域移除全局 `<header>`，包括当前页面名称、分隔符和说明文字。左侧品牌区与导航栏保持不变。各功能页面已有的自身标题继续作为页面识别，内容区仍为可滚动区域，获得原顶栏的高度。

## 安全与兼容性

本次不改变 Profile 配置、凭据、二维码、TOML、FRPC 生命周期或批量删除的凭据清理路径。规则预览与详情仍不得渲染 Token、密码、私钥、`rawToml` 或整个配置对象。
