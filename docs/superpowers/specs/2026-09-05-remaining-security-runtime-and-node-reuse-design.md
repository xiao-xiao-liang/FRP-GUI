# 剩余安全、运行时与节点复用设计

## 范围与顺序

1. 下载 IPC 以 `releaseTag`、`assetName` 和受控镜像标识作为输入；Rust 验证身份后自行构造官方 URL 与镜像传输 URL。
2. 日志虚拟列表以每个可见行的实测高度计算偏移与可视范围，换行不再依赖固定 28px 行高。
3. Profile 持久化仅保存非敏感元数据；Token 与含秘密的 TOML 通过 Profile 专属凭据引用写入 Keyring。旧 localStorage 数据在读取时迁移并删除秘密字段。二维码由本地生成器基于脱敏配置摘要生成；复制与导出完整配置要求用户显式确认其包含秘密。
4. 场景向导可选择已部署且运行中的 FRPS 节点，回填主机和端口；Token 通过节点凭据引用获取，不显示或持久化到 Profile。

## 安全边界

浏览器预览不访问 Keyring、不会生成带配置内容的网络二维码、不能创建可运行的凭据化 Profile。桌面端只允许读取与所选节点匹配的 `frp_token`，不向前端返回 Token 以外的服务器凭据。
