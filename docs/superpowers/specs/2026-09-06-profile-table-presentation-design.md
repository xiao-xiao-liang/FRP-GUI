# 我的连接表格化呈现设计

## 目标

将“我的连接”从卡片/表格双视图收口为单一表格视图，采用紧凑的连接级列表。表格使用项目现有飞书组件与 SVG 图标资源；右侧操作列固定，连接规则以简洁映射预览和规则详情弹层呈现。

## 表格结构

默认且唯一的呈现方式为表格，移除卡片视图状态、切换按钮和卡片分页分支。保留类型、分组、标签、关键词和排序筛选；移除“全部连接、运行中、已停止、异常待处理”四个状态 Tab，以及页面级“全部启动”“全部停止”按钮。

列顺序固定如下：

1. 选择框；
2. 连接名称；
3. 连接描述；
4. 运行状态；
5. 穿透规则；
6. 上次启动；
7. 操作。

不显示服务端、流量/连接、分组或标签列。连接名称单元格只显示名称与置顶标识，不显示描述、分组或标签。分组和标签仍只用于筛选、组织和编辑，不改变其数据模型或持久化边界。

“上次启动”读取 `profile.stats.startTime`，其含义为该 Profile 最近一次进入 `running` 状态的时间；无值显示 `—`。不新增第二个时间字段。

## 描述与规则详情

描述列单行截断。描述为空显示 `—`；有描述时用现有 `FeishuTooltip` 承载完整文本，避免表格因长描述增高。

规则列只显示端口映射预览，每行格式为：`协议类型 本地端口 → 远程端口`。不显示规则名称、本地 IP 或域名。规则数量为一至三条时纵向显示所有映射，并随预览行数从正常字号递减至紧凑字号；表格行可自然增高以完整容纳三行。

规则超过三条时显示前两条映射，第三行替换为“查看更多（+N 条）”。整列预览区域均可点击，并使用手型指针；点击后打开 `FeishuDialog`，内部使用 `FeishuDataTable` 展示该连接全部规则的名称、协议类型、本地 IP、本地端口和远程端口。缺失字段显示 `—`。规则详情只读，不引入规则独立启停、删除或编辑。

## 固定操作列

“操作”列配置 `fixed: 'right'` 并保留明确宽度，复用 `FeishuDataTable` 已有的横向滚动与固定右列阴影逻辑。只有表格数据区横向滚动，固定列及其表头不移动。

操作列使用项目已有 SVG：启动使用 `RunIcon`，停止使用 `StopIcon`，删除使用 `DeleteIcon`；所有图标按钮均有 `aria-label` 和 `FeishuTooltip`。启动、停止不显示文字。运行中显示停止图标；已停止显示启动图标；启动中或停止中显示禁用的 `RefreshIcon`；错误状态保留既有修复核心或查看日志入口。

## 严格批量操作

没有选中连接时不显示任何批量操作区域，也不显示“已选择 N 项”文字。选中一项或多项后，仅显示删除、启动和停止三项操作：

| 操作 | 可用条件 | 结果 |
| --- | --- | --- |
| 启动 | 所有选中连接均为 `stopped` | 串行启动全部选中连接。 |
| 停止 | 所有选中连接均为 `running` | 确认后串行停止全部选中连接。 |
| 删除 | 所有选中连接均为 `stopped` | 确认后串行删除并清理系统凭据。 |

任何混合状态、`error`、`starting` 或 `stopping` 都使对应批量按钮禁用。禁用按钮外包可悬浮元素，使用 `FeishuTooltip` 说明可用条件。批量执行期间，三个按钮、选择框和固定列操作保持既有 `isBatchOperating` 禁用行为。

批量移动分组不出现在本次表格工具条；不得删除已有分组数据或其持久化逻辑。

## 模块职责

- `src/features/profiles/ProfileList.tsx`：单一表格视图、列定义、选择状态、严格批量资格与规则详情弹层状态。
- `src/features/profiles/ProfileRuleDetailsDialog.tsx`：将 `ProxyRule` 映射为只读飞书表格并显示在弹层中。
- `src/services/profile-organization.ts`：将批量目标资格改为严格的“全部状态一致”规则，供 UI 与 App 共用。
- `src/App.tsx`：在应用层再次执行严格状态验证，防止绕过 UI；复用既有 FRPC 生命周期与凭据清理。
- `src/components/ui/feishu-table/FeishuDataTable.tsx`：不改行为，直接使用既有 `fixed: 'right'` 能力。

## 安全与兼容性

本次只变更呈现与批量资格规则，不变更 Profile、TOML、Token、二维码或系统凭据库的存储边界。规则详情不得显示认证 Token、密钥、密码、TOML 或其他秘密。所有新增文案和注释使用简体中文。
