# 桌面托盘与设置页设计

## 目标

让 FRP-GUI 在桌面端可作为后台常驻应用使用，并让用户自行决定窗口关闭、应用启动和退出时的行为。

## 范围

新增“设置”页面和原生托盘菜单。首版只覆盖：关闭主窗口、启动时窗口显示、退出前确认。不开启系统开机自启，也不自动启动任何 Profile。

## 设置模型

前端将 `AppSettings` 存入 `localStorage` 的 `frp_gui_settings` 键：

- `closeBehavior`: `hide_to_tray`（默认）或 `exit_app`；
- `launchBehavior`: `show_window`（默认）或 `start_minimized`；
- `confirmExitWhenRunning`: 默认 `true`。

浏览器预览只允许修改和保存该模型，不会触发窗口、托盘或进程操作。

## 原生行为

Rust 在应用启动时建立托盘，菜单包含“打开主窗口”“停止全部连接”“退出应用”。点击托盘图标将主窗口恢复、显示并聚焦。

前端在设置变化时通过受限 IPC 通知后端。关闭窗口时，后端读取当前设置：隐藏模式阻止关闭并隐藏窗口；退出模式在无运行连接时由后端直接停止所有 FRPC 进程后退出。运行连接且设置要求确认时，前端在关闭主窗口前请求确认；确认后调用受控退出命令。托盘“退出应用”是明确的退出操作，后端不经 WebView 回调，直接停止所有 FRPC 进程后退出。

托盘初始化失败时，应用继续以普通窗口运行；关闭请求按退出处理，避免窗口被隐藏后无法恢复。

## 测试

前端测试覆盖默认值、设置持久化、设置页面渲染和 IPC 参数。Rust 单元测试覆盖设置解析、关闭决策和菜单标识。完整构建后通过 Rust 编译检查原生 API。
