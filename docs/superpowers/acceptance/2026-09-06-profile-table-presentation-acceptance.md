# 我的连接表格化呈现验收清单

## 自动化验证

实现完成后执行：

- `pnpm test`
- `pnpm build`
- `cargo test --manifest-path src-tauri/Cargo.toml`
- `git diff --check`
- `git status --short`

通过条件：测试与构建零失败，`git diff --check` 无错误，既有未提交改动未被覆盖或清理。

## 表格与列

- 打开“我的连接”时，直接显示表格，不存在卡片/表格视图切换。
- 页面没有“全部连接、运行中、已停止、异常待处理”状态 Tab，也没有页面级“全部启动”“全部停止”按钮。
- 列顺序为选择、连接名称、连接描述、运行状态、穿透规则、上次启动、操作。
- 表中不显示服务端、流量/连接、分组或标签列；名称列不显示描述、分组或标签。
- 描述为空显示 `—`；长描述在单行截断后，鼠标悬浮显示完整文本。
- `stats.startTime` 有值时“上次启动”显示本地时间，无值显示 `—`。
- 缩窄窗口并横向滚动表格时，右侧操作列表头与内容固定，其他列可滚动。

## 规则预览与详情

- 规则数量一至三条时，规则列纵向显示每条 `协议类型 本地端口 → 远程端口`。
- 四条规则时，规则列只显示前两条和“查看更多（+2 条）”；预览区域有手型指针。
- 点击任意规则预览区域，打开只读详情弹层。
- 弹层使用飞书表格呈现全部规则的名称、协议类型、本地 IP、本地端口、远程端口；缺失字段显示 `—`。
- 详情弹层不出现 Token、密码、密钥、TOML 或其他凭据。

## 操作与选择

- 单项启动与停止均为项目 SVG 图标按钮，无文字；悬浮可获得动作说明。
- 选中零项时，不显示批量操作区与选择数量文字。
- 选中一项或多项时，仅显示删除、启动、停止。
- 所选连接全部为 `stopped` 时，启动和删除可用，停止禁用。
- 所选连接全部为 `running` 时，停止可用，启动和删除禁用。
- 选择中包含混合状态、`error`、`starting` 或 `stopping` 时，三个批量按钮全部禁用，并说明原因。
- 停止与删除仍要求确认；删除后通过既有路径清理系统凭据。
- 批量执行期间，选择框、批量按钮和单项操作按钮均不能重复触发。
